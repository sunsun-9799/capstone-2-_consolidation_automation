# 캡스톤 디자인 2 — 15주차 계획안

연결회계(Consolidation) 자동화 프로그램을 구현하는 캡스톤 디자인 프로젝트입니다. 자회사 재무제표 및 내부거래(Trading Partner) 데이터를 입력받아 연결조정(단순합산, 상계, 미실현손익 제거, 지분법)을 자동 계산하고, 조정 근거와 통제 취약점을 탐지하는 검증 리포트를 생성하는 것을 목표로 합니다.

## 1~2주차 — 주제 결정 및 계획 설정

| 주차 | 내용 |
| --- | --- |
| 1주차 | 주제 결정 — 연결회계 자동화 프로그램 방향 확정 |
| 2주차 | 계획 설정 — 전체 일정 및 연구 범위 수립 |

## 3~5주차 — 설계

| 주차 | 내용 |
| --- | --- |
| 3주차 | 요구사항 정의 — 기능/데이터/비기능 요구사항 명세 |
| 4주차 | 가상 데이터 생성 — 자회사 그룹 재무제표 및 분개(Trading Partner 포함) 생성 |
| 5주차 | 시스템 아키텍처 설계 — 모듈 구조 확정, 기술스택 세팅 |

## 6~9주차 — 연결조정 로직 구현

| 주차 | 내용 |
| --- | --- |
| 6주차 | 단순합산 로직 구현 — 자회사별 재무제표 합산 |
| 7주차 | 내부거래 상계 로직 구현 — Trading Partner 기반 자동 필터링 및 상계 처리 |
| 8주차 | 미실현손익 제거 로직 구현 — 재고자산 내 미실현이익 계산 및 차감 |
| 9주차 | 지분법·비지배지분 계산 로직 구현 |

## 10~11주차 — 검증 리포트 및 웹 UI

| 주차 | 내용 |
| --- | --- |
| 10주차 | 검증 리포트 기능 구현 — 조정 근거 로그, 필드 누락 등 통제 취약점 탐지 로직 |
| 11주차 | 웹 UI 개발 및 전체 모듈 통합 — 업로드, 실행, 결과(연결재무제표·검증리포트) 화면 |

## 12~13주차 — 테스트 및 시나리오 검증

| 주차 | 내용 |
| --- | --- |
| 12주차 | 기본 시나리오 테스트 — 정상 케이스 전 과정(합산~검증리포트) 검증 |
| 13주차 | 이상 케이스 테스트 — Trading Partner 누락 등 의도적 오류 삽입 후 탐지 여부 확인, 결과 정리 |

## 14~15주차 — 리포트 작성 및 최종 제출

| 주차 | 내용 |
| --- | --- |
| 14주차 | 최종 리포트 작성 — 설계, 구현, 테스트 결과 정리 |
| 15주차 | 최종 제출 |
