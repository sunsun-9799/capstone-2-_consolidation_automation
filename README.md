# capstone-2-_consolidation_automation
consolidated-financial-statements-automation

연결회계(Consolidation) 자동화 프로그램 — 캡스톤 디자인 2 프로젝트

자회사 재무제표 및 내부거래(Trading Partner) 데이터를 입력받아 연결조정(단순합산, 투자주식·자본 제거, 상계, 미실현손익 제거, 지분법)을 자동 계산하고, 조정 근거와 통제 취약점을 탐지하는 검증 리포트를 생성합니다.

## 진행 현황

- [x] 1~2주차: 주제 결정, 계획 설정
- [x] 3주차: 요구사항 정의 (ChatGPT 피드백 반영 개정)
- [ ] 4주차: 가상 데이터 생성
- [ ] 5주차: 시스템 아키텍처 설계
- [ ] 6~10주차: 연결조정 로직 구현
- [ ] 11~12주차: 검증 리포트 및 웹 UI
- [ ] 13주차: 테스트 및 시나리오 검증
- [ ] 14~15주차: 리포트 작성 및 최종 제출

## 기술 스택
